# SteveTheTroll

Fluffy Slippers: soft plush slippers worn in the utility slot (armor, frost resistance). Wear them and see what happens. A fluffy costume follows later.

## Features
- **Fluffy Slippers**, crafted at the workbench (level 1): 5 Troll hide, 4 Deer hide, 6 Blueberries.
- Utility slot: armor 5 (+1 per quality, up to quality 4), frost resistance. Every upgrade costs 2 Troll hide + 2 Blueberries.

## How to use
- Press **F6** (config `[General] MenuKey`) to open the SteveTheTroll menu.
- Build pieces of this mod are in the hammer's **KY-Items** category.

## Configuration
`BepInEx/config/com.kydldev.SteveTheTroll.cfg` (or the in-game config manager):

| Section | Setting | Default | What it does |
|---------|---------|---------|--------------|
| General | EnableAll | true | Switches the whole mod on / off while playing |
| General | MenuKey | F6 | Opens / closes the menu |
| DebugLog | Enable | false | Detailed lines in the BepInEx log for bug reports |

Edits to the file are picked up while the game runs.

## Multiplayer
Every player needs the mod (same minor version).
